4つのパーツの決め方

「ユーザーが何をしたいか」の流れに沿って、画面を4つに分けました。

A
入力エリア
音声 / テキスト

現場では手が塞がっていることが多いため、音声入力を最優先に配置。テキスト入力はサブ扱いにして、マイクボタンを画面中央の大きな丸に。

B
生成ボタン
1アクション

「次に何をすればいいか」を明確にするため、ボタンは1つだけ。大きく・オレンジで目立たせて迷わせない設計に。

C
ToDoカード
期限・担当

AIに「期限・対象者・やること」の3要素で構造化させることで、読まなくても内容がわかるカード表示に。重要度順に並ぶ。

D
完成文 + LINE送信
即共有

作った文章を使ってもらえなければ意味がないため、LINEで全部送るボタンを大きなメインCTAに。個別送信はサブに格下げ。

④

デザインの工夫

📱
モバイルファースト

介護現場はスマホがメイン。タップしやすい大きなボタン（44px以上）・大きめフォント・スクロールを最小限にするレイアウトを採用。

🟠
オレンジで統一

「緊急性・行動を促す」イメージのオレンジをメインカラーに。ToDoカードは温かみのあるオレンジ背景、完成文は落ち着いた白背景と使い分け。

💬
LINEブラウザ対策

LINEのトーク内リンクから開くと音声入力できない問題を検知。「Safariで開く」ボタンを自動表示してユーザーを誘導する仕組みを実装。

⏳
スケルトンローディング

AI生成中は「灰色のシマシマ（スケルトン）」を表示。「固まった？」と不安にならないよう、待ち時間を視覚的に伝える工夫。

🟢
LINEカラーで送信感

送信ボタンにLINE公式カラー（#06C755）を使用。「これを押せばLINEに飛ぶ」とひと目でわかるように。アイコンもLINEのロゴ形状のSVGを使用。

🔔
トースト通知

コピー成功・エラー時に画面下部から「コピーしました」などのポップアップを表示。ダイアログ（ポップアップ確認）を使わず、操作を止めないUXに。

⑤

ぶつかった課題と解決方法

課題1
APIキーの切り替え時にJavaScriptが全部動かなくなった
OpenAI→Geminiに切り替えた際、URLのテンプレートリテラル（バッククォートで囲む文字列）が消えてしまい、ページ全体が白くなって音声入力も使えなくなった。
❌ 誤: fetch(https://.../${model}...) ← バッククォートなし
✅ 正: fetch(`https://.../${model}...`) ← バッククォートあり
→ 解決：ブラウザの開発者ツールでエラーを確認し、バッククォートの欠落を特定して修正
課題2
OpenAI APIの残高切れでツールが使えなくなった
「生成する」を押すとエラーメッセージが出てAIが使えなくなった。OpenAI APIはクレジット（前払い残高）を消費するため、残高が0になると止まる。
→ 解決：無料枠のあるGemini API（Google製）に切り替え。月あたりの無料呼び出し回数が多く、個人利用なら実質無料で使い続けられる
課題3
LINEアプリ内ブラウザでは音声入力できない
LINEのトーク内のリンクをタップして開くと、マイクボタンが反応しない。LINEの内蔵ブラウザは音声API（Web Speech API）に対応していないため。
→ 解決：ユーザーエージェント（ブラウザの識別情報）を検知してLINEアプリ内と判断したら、「Safariで開く」ボタンを自動表示する仕組みを実装
課題4
LINEボタンが多すぎて「どれを押せばいい？」状態になった
「ToDoだけ送る」「完成文だけ送る」「両方送る」「コピーする」で6つのボタンが並び、現場で使うには認知負荷が高すぎた。
→ 解決：「LINEで全部送る」を大きなメインボタンに一本化。個別送信は小さなサブボタンとして横並びに格下げ。UI/UXレビューで指摘されて気づいた改善点
⑥

使った技術と選んだ理由

技術 用途 選んだ理由
HTML / JS
単一ファイル		 アプリ全体 インストール不要・GitHubに上げるだけで公開できる。フレームワーク不要でシンプル
Tailwind CSS
CDN		 デザイン クラス名を書くだけでスマホ対応のデザインが作れる。CSSを別ファイルにしなくていい
Gemini API
Google製AI		 文章生成 無料枠が大きく個人利用で実質無料。日本語の精度が高く、JSON形式で安定して返答してくれる
Web Speech API
ブラウザ標準		 音声入力 追加ライブラリ不要。iPhone Safariで使えるブラウザ標準の音声認識API
GitHub Pages
無料ホスティング		 公開・デプロイ GitHubにファイルをアップするだけで自動公開。サーバー代0円。URLを誰にでも共有できる
